# Listora

Property marketplace and property-management application built with Laravel, Blade, Alpine.js, Tailwind CSS and Vite.

## Work represented
- Responsive public marketplace and property details experience
- Multi-role accounts and workspace switching
- Agent, landlord and tenant onboarding
- Verification and moderation workflows
- Property listing wizard, media handling and listing lifecycle controls
