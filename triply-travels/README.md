# Triply Travels Platform

PHP and SQLite travel-services platform combining a public website with customer, travel-agent and administrator workflows.

## Work represented
- Customer registration, profiles and service requests
- Agent work queue, messaging and request management
- Administrator dashboards and CMS tools
- Role-based access, validation and security controls
